# 如何使用

## 准备工作
请检查您的其它插件的功能是否与本插件重复，如果重复请关掉对应插件或关闭本插件的对应功能。

之前骂了 BLG 一句，现在道个欠。

兼容 Better Luogu 1.13。

:::warning

本插件融合了许多插件，基本上可以关掉所有的其他插件了。

本插件不保证兼容其他插件。

:::

## 打开设置 / 搜索
本插件将搜索与设置、诗词、历史上的今天放在了一起。

当您没有搜索时，就会显示设置、诗词、历史上的今天，否则显示搜索结果。

支持快捷键 `Ctrl + ;`（分号）快速开关搜索 / 设置面板。

也可以点击右下角的搜索按钮打开搜索 / 设置面板，点击空白处关闭搜索 / 设置面板。

设置面板右边是公告、功能开关，下滑是每项功能的具体设置。


## 私信 Markdown 渲染
全网第一个私信支持 Markdown、KaTeX 与 HTML 的插件！

会定时自动渲染，无需手动。

支持 HTML。

:::warning

KaTeX 请使用标准语法，否则可能无法正常渲染！

由于私信很少使用代码块，所以代码块不会高亮！

请注意链接可自动识别，但图片需要标准 Markdown 语法：

```markdown
![](https://cdn.luogu.com.cn/upload/image_hosting/jqg4pnih.png)
```
:::


## 题目颜色显示
思路来源于斯老板的插件。

找到题号并修改其颜色为对应的难度色。


## 复制 Markdown
支持专栏、题单、比赛、讨论界面。

其中专栏、题单、比赛界面按下 `Ctrl + Alt + C` 复制内容，随后会弹出弹窗提示是否复制成功。

还写了暂时全网唯一的讨论区复制源码，主内容以及每个回复都设有复制按钮。


## 双击跳题器
在洛谷内双击题号即可跳转至对应洛谷题目。

同时还支持以下快捷键组合：`Ctrl+Shift+J`、`Ctrl+Shift+G`、`Ctrl+Shift+M`、`Ctrl+Shift+V`、`Ctrl+Shift+L`，方便不同习惯的用户。

:::warning

由于题目 ID 多样性，AT 的古怪题号可能无法全部识别。

跳转前不会检查题目是否存在，若不存在会进入 404 页面。

:::

## 首页自动签到
如果当天未签到，进入首页将自动完成签到，并弹出桌面通知（需授权）。

:::warning

签到结果以洛谷实际返回为准，本插件仅模拟点击。

不包含“大吉”等玄学提示，避免误导。

:::

## 首页犇犇自动展开与屏蔽用户
自动点击犇犇的“点击查看更多...”按钮，无限加载更多犇犇。

在设置面板中可以添加要屏蔽的用户 UID（逗号分隔），被屏蔽用户的犇犇将被自动过滤。

## 比赛报名按钮解锁器
Rated 比赛无需等待五秒倒计时即可直接报名。

:::warning

仍然需要手动点击“报名”按钮。

解锁仅针对前端倒计时，不影响后端校验。

:::

## 长代码自动套折叠框
所有代码块（`<pre><code>`）都会自动添加折叠框。若代码行数超过阈值（默认1500字符），自动折叠；否则自动展开。点击折叠框可切换展开/收起状态。

同时内置危险代码扫描功能（仅标记提醒，不执行任何操作），对高危、可疑代码给出警示标签。


## 自动跳转保存站
当您访问洛谷国际站（`www.luogu.com`）的文章（`/article/`）或剪贴板（`/paste/`）时，自动跳转到保存站对应链接（默认 `luogu.me`，可在设置中切换为 `luogu.amlg.top`）。若遇到安全访问中心，也会自动改写跳转链接。

## 全网犇犇 & 犇犇龙王榜
* 全网犇犇：在首页犇犇标签页增加“全网犇犇”，展示来自 `benben.sbs` 的最新 100 条犇犇。
* 犇犇龙王榜：在首页显示每日发犇数量前十的用户，以 Markdown 表格形式呈现，支持头像和用户名跳转。

## 用户标记
在首页“用户标记”模块，可以为任意用户 UID 设置备注标记。之后在该用户的主页，用户名旁会显示该标记（例如“大佬”）。

同时支持删除已设置的标记。

## 按 Ctrl+Enter 发送犇犇
当光标聚焦在犇犇输入框时，按下 `Ctrl`（Windows）或 `Command`（Mac）加 `Enter` 键，即可快速发送犇犇。

## 任务计划增强
在首页“任务计划”模块，自动隐藏已完成的题目，并添加“随机”按钮。点击后会从未完成的题目中随机挑选一道跳转。

## 运行命令
按下 `Ctrl+K` 打开命令面板，支持以下命令：

* `goto <url>`：跳转到指定网址
* `discuss <did>`：跳转到指定讨论帖
* `discusssection <forum>`：跳转到讨论区板块（siteaffairs / problem / academics）
* `uid <uid>`：跳转到指定用户主页
* `uname <username>`：根据用户名搜索并跳转
* `help [command]`：显示帮助信息
* 仅列出部分，所有命令可以使用`help`命令查看

## 创建重现赛
在比赛页面（`/contest/xxx`）添加“创建重现赛”按钮。点击后选择开始时间，自动复制原比赛题目并创建新比赛（可见性为“仅限邀请”），无需手动设置。

## 自动填充字母验证码
当出现图形验证码（字母数字组合）时，自动调用 OCR API 识别并填充到输入框。支持多种弹窗样式（如提交题目、上传图片等）。

## 题目数量对比
在他人主页的“练习”页面，各难度题目数量旁会显示“你的题数 / 对方题数”，并用绿色（你更多）或红色（你更少）标识。

## 自动打开 O2 优化
在题目 IDE 页面（`#ide`）和提交页面（`#submit`），自动勾选“O2 优化”选项，无需手动操作。

## 跳转到 VSCode Luogu
在题目页面和比赛页面添加按钮，点击后向本地 VSCode 插件（端口可配置）发送请求，实现在本地 IDE 中打开题目/比赛。

需提前安装 VSCode 插件 `AmazingLuoguDevTeam.vscode-luogu-api`。

## 显示 Codeforces 原始难度
对于洛谷上的 CF 题目（`CFxxxx`），在题目标签位置显示 Codeforces 官方难度分（rating）。数据每 24 小时从 CF API 更新一次。

## 保存讨论到 luogu.store
在讨论帖页面，按下 `Ctrl+S` 可将当前帖子的完整内容保存到第三方保存站 `luogu.store`（需网络通畅）。

## 显示用户介绍
在用户主页（非管理员、非实名认证用户），自动解析个人简介中的 Markdown 和 LaTeX，并渲染为美观的卡片。同时提供“复制原始内容”和“渲染为 HTML”按钮。

## 缩写查询（能不能好好说话）
选中页面上的英文缩写（如 “yyds”），会弹出小窗显示其可能的含义。数据来自 [nbnhhsh 项目](https://lab.magiconch.com/nbnhhsh/)，支持提交新翻译。

## 随机跳题
* 在题目列表页：根据当前筛选条件（题目类型、难度、标签、关键词），随机跳转到一道符合条件的题目。
* 在题单页：点击“随机跳题”按钮，从当前题单中随机挑选一道题目。

## 保存站更换
若您习惯使用自建的保存站，可在设置中切换为 `luogu.amlg.top`，所有保存站跳转将使用该域名。

## 私信桌面通知
通过 WebSocket 实时监听私信，收到新消息时弹出桌面通知（含发送者头像、昵称和内容预览），点击可直接进入聊天窗口。

## 专注模式
开启后可根据个人需求隐藏洛谷上的各类干扰元素，例如：

* 隐藏指定页面（私信、消息、专栏、题解、比赛、用户主页等）
* 隐藏导航栏按钮、侧边栏、页脚、广告、运势、友情链接、标签、排名、犇犇列表等
* 隐藏题目页的统计、题解、反馈、提供者、个人/团队题单、标签、讨论等
* 隐藏题单页的统计信息和操作按钮
* 隐藏记录页的筛选器

被隐藏的页面会显示“请认真学习哦！”倒计时后自动关闭。

## 表情渲染（QQ 风格）
自动将 `/微笑`、`/bx` 等 QQ 风格表情代码转换为对应的 GIF 图片。支持所有包含文本内容的区域（讨论、犇犇、私信、用户简介等）。

同时提供一个表情选择面板，快捷键 `Ctrl+Shift+E` 打开，点击表情即可在当前输入框中插入表情代码。

## 首页用户搜索
在首页增加“用户搜索”模块，输入用户名或 UID 可直接跳转到用户主页。

## 首页讨论列表长度限制
可设置首页显示的讨论帖子数量（4~16 条），超出部分自动隐藏。

## 个性化签名时间提示
在用户主页签名处，显示该用户的最后在线时间（仅 Amazing Luogu 用户可见，不适用洛谷 API）。格式可自定义，例如 `{time} || {slogan}`。

## 自定义备忘录
在设置面板编辑备忘录内容（支持 Markdown、KaTeX、HTML），该备忘录会插入到首页犇犇区域上方。

## 自定义字体
提供一个字体文件 URL（需支持跨域），脚本会将其加载为 `AML-CustomFont` 字体族。之后可在“自定义样式”中通过 `font-family: "AML-CustomFont";` 使用。

## 自定义样式
在设置面板编写任意 CSS 代码，可选择注入到 `<head>` 或 `<body>`，实时生效。支持保存后自动刷新样式。

## 随机古诗（一言）
首页面板显示一句一言（来自 [uapis.cn](https://uapis.cn) API）。数据每日更新一次。

## 历史上的今天
首页面板显示当天在程序员界或科技界发生的历史事件，包含年份和简要描述。数据每日更新一次。

## 其他
其他还有很多功能，可以自己探索。
